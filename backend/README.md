# Backend Structure

This folder contains the backend scaffold for the AI Skin Care project.

## Files and folders

- `models/` - Stores the trained skin disease model file.
- `uploads/` - Directory for uploaded images or files.
- `main.py` - Entry point for the backend application.
- `predict.py` - Placeholder for prediction-related logic.
- `requirements.txt` - Python dependencies for the backend.
- `README.md` - Overview of the backend structure.

No application logic has been added yet.
